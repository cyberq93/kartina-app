# Дорожная карта и передача работы

Файл для следующей сессии (Claude Code на ПК владельца). Прочитайте его
вместе с README.md и deploy/SETUP.md.

## Состояние на 2026-10-14

Работает: движок смешивания (Кубелка-Мунк, до 2 красок в смеси, ΔE2000),
сегментация, разметка, PDF (контур в размер холста + лист палитры),
интерфейс оператора (`python -m pbn_engine.ui`, http://127.0.0.1:8080),
закрытый API для сайта (отложен). 54 теста проходят. Владелец запустил
программу на Windows (Python 3.14.7) и проверил на реальном фото.

## Решения владельца (обязательны)

- Сайт пока не подключаем, архитектуру под него сохраняем. Рецепты смесей
  наружу (в API для сайта) не отдаются никогда: только две картинки
  (контур и раскрашенный результат).
- Палитра: краски Brauberg, около 54 цветов. Их и используем.
- Печать: 300 dpi, а не текущие ~81.
- Сервер: отдельный ПК с Ubuntu Server, туннель Cloudflare (позже).

## Задачи по порядку

1. **Печать 300 dpi.** Сейчас обработка ограничена 1600 px по длинной
   стороне. Для холста 40x50 см при 300 dpi нужно около 4724x5906 px.
   Варианты: считать сегментацию на уменьшенном изображении, а границы
   регионов затем строить в полном разрешении (апсемплинг карты меток с
   сглаживанием); либо векторный контур в PDF (кривые вместо пикселей),
   это лучший вариант для печати. Проверить память: 50 Мп x несколько
   массивов.
2. **Более детальная сегментация.** Владелец считает разметку слишком
   простой: нужен гораздо больший диапазон оттенков. Проверять на
   реальных портретах: кожа (тени, полутени, света, румянец), волосы,
   одежда. Идеи: больше кластеров (сейчас 8–40), делить кластеры по
   яркости внутри крупных областей, ограничивать минимальный размер
   региона физически (в мм на холсте, а не в долях кадра), отдельная
   обработка лица. Добавить тесты на реальных образцах.
3. **Палитра Brauberg.** Нужен файл `palette.json` (формат: см.
   `pbn_engine/palette.py`, `load_palette_from_json`; путь через
   `PBN_PALETTE_PATH`). Важно: RGB из картинки каталога или экрана
   неточны. Для точного смешивания лучше измерить реальные мазки
   (фото выкрасов при ровном свете со шкалой, либо спектрофотометр).
   Первый приближённый вариант допустим, но смеси нужно сверять с
   реальным замесом и поправлять.
4. **Сверка смесей с реальностью.** Сделать 5–10 замесов по рецептам
   программы, сфотографировать, сравнить с целью. Подогнать
   коэффициенты рассеяния (S) в `mixing.py`.
5. Размеры холстов: заменить придуманные пресеты на 15 реальных размеров
   владельца (PRESETS в `ui.py`).
6. Позже: до 3 красок в смеси, лицо-ориентированная обрезка, подключение
   сайта, настройка серверного ПК, 152-ФЗ.

## Как работать

- Запуск: `python -m pbn_engine.ui` из папки, где лежит `pbn_engine`.
- Тесты: `python tests/test_X.py` для каждого файла.
- Пользователь не программист и хочет учиться: объяснять изменения
  простыми словами, по возможности показывать результат картинкой.
- Фото клиентов не сохранять на диск, не коммитить (в .gitignore).
