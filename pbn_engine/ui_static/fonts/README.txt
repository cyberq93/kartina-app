Шрифты интерфейса лежат рядом с программой, чтобы страница выглядела одинаково
на любом ПК и работала без интернета.
- Lora (Cyreal) и Inter (Rasmus Andersson): свободные шрифты под лицензией
  SIL Open Font License 1.1. Тексты лицензий лежат в репозиториях проектов
  (github.com/cyrealtype/Lora-Cyrillic, github.com/rsms/inter); при публикации
  программы вне студии приложите их.
